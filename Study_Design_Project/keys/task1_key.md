## Scoring Notes

- A finding counts if the participant identifies the correct UI element **and** the correct nature of the mismatch, even if they cite a different but still applicable requirement ID or phrase the requirement in their own words. See the point distribution below:
- **Requirement Violated**. Full credit (1 pt) if the violation matches the item described above; otherwise, no credit (0 pt).
- **Problem Type**. Full credit (1 pt) if the type matches the item described above; otherwise, no credit (0 pt).
- **Screen & UI Element**. Full credit (1 pt) if the screen and the UI element are both correct; partial credit (0.5 pt) if either the screen or the UI element is correct; otherwise, no credit (0 pt).
- **Issue Description**. Full credit (1 pt) if the description is reasoned; partial credit (0.5 pt) if it is vague or ambiguous; otherwise, no credit (0 pt).
- **User Workflow Impact**. Full credit (1 pt) if the description is reasoned and based on the use case/user stories; partial credit (0.5 pt) if it meets only one of the two; otherwise, no credit (0 pt). Only #4's "No UC/US affected" counts as correct.
- Total points: **20** pts. (4 reported problems × 5 pts per problem)
