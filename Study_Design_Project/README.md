# GenAI Software Development User Study Tasks

## Overview of the Study

This project repo contains the materials for the user study. You will work on three SE-related tasks built around a fictional event registration web app, **EventConnect**. The goal of this study is to see how GenAI impacts how you solve software development tasks and learn SE-related concepts (e.g., functional requirements, use case, user story, usability heuristics.) Your goal is **not just to solve the tasks but also to try to understand** the tasks and relevant concepts.

---

### Task 1 — Requirement Review

For task 1, you will act as a requirements reviewer to do a requirements audit. Your job is to review the software requirements specification (`task1/srs.md`) against the wireframe in the [Figma](https://www.figma.com/design/OeF6UuLMeyI46GlMwDd7fA/EventConnect?node-id=0-1&t=FtRi67boQdjaZkoZ-1) and report 4 places where they mismatch in the `task1/REPORT1.md` file by following the **given example** in the table.

### Task 2 — Usability Review

For task 2, you will act as a UX reviewer to do a usability audit of the user interface. Your job is to use the functional app (`task2/app_task2`) like a real user and report 4 UI usability problems (following Nielsen's 10 usability heuristics) in the `task2/REPORT2.md` file by following the **given example** in the table.

### Task 3 — Feature Implementation

For task 3, you will act as a developer to do a design-to-code implementation. Your job is to implement a **"Select & Cancel Multiple"** feature on the My Registrations page of the app (`task3/app_task3`) so that it matches the high-fidelity mockup (`task3/CancelMultiple_Design.pdf`).

To start with each task, please check the`INSTRUCTIONS.md`for details inside each task folder (`task1/, task2/, task3/`).

## Before Start

Please note the following:

* You can use the **Google AI Studio**'s Code and Chat feature: chat-based prompts and file upload (**limited to text files**).
* We encourage you to use the AI tool to help you solve the tasks throughout the session.
* You can use **any browser to search the web** for help or solutions
* You may **not** use any web-based AI platforms (e.g., ChatGPT), IDE-integrated coding agents (e.g., Copilot or Claude Code), or third-party extension (e.g., Cline).
* You will have **15-20** minutes to complete each task.
* You will **think aloud** throughout the sessions.
